PARKS ONE — VERSIÓN LISTA PARA PUBLICAR

Este paquete parte exactamente del proyecto que subiste y solo corrige el orden de carga:

1. Supabase carga parques y documentos reales.
2. Después se calculan las vistas y botones.
3. Los botones usan storage_path (UUID/carpeta/archivo) y no las rutas antiguas documents_repo.

NO incluye carpeta .git para evitar rebases o conflictos anteriores.
NO modifica Supabase, Storage, usuarios, políticas ni los documentos ya cargados.
NO vuelvas a ejecutar schema.sql.
NO vuelvas a importar los documentos.

PUBLICACIÓN RECOMENDADA EN TU REPOSITORIO ACTUAL:
1. Haz una copia de respaldo de tu carpeta actual.
2. Copia todo el contenido de esta carpeta sobre tu proyecto local.
3. Conserva únicamente la carpeta .git de tu proyecto actual.
4. En Git Bash ejecuta:
   git add -A
   git commit -m "Corrige carga de documentos reales"
   git pull --rebase origin main
   git push origin main

Si Git indica conflicto, NO continúes. Usa un repositorio nuevo o sube estos archivos desde GitHub.

VERIFICACIÓN:
- La consola debe mostrar cloud.js?v=6.2.2
- Al pulsar Ver / descargar, la ruta debe comenzar con un UUID, por ejemplo:
  8b01e752-.../AGUA/...
- No debe comenzar con documents_repo/
